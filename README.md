# Codeforces Solutions

A collection of my solutions to [Codeforces](https://codeforces.com/) problems, organized by problem rating and contest.

## Repository structure

- `800/` – problems rated 800
- `900/` – problems rated 900
- `1000/` – problems rated 1000
- `1100/` – problems rated 1100
- `1200/` – problems rated 1200
- `1300/` – problems rated 1300
- `contest/` – solutions grouped by contest

Most solutions are written in Go, with some C++ solutions included where noted.

## Running a solution

### Go

```bash
go run 800/263A.go
```

### C++

```bash
g++ -std=c++17 1000/cpp_solutions/solution_849A.cpp -o solution
./solution
```

Solutions read input from standard input, as expected by Codeforces. Copy the problem's sample input into the terminal when testing locally.

## Disclaimer

These solutions are intended for learning and reference. Try solving the problems yourself before checking the implementations.
